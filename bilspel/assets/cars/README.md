# Car images

AI-generated with the built-in ImageGen tool for Max Night Drive. Each WebP contains a front three-quarter view and a direct rear view on transparent backgrounds. Source images are retained in the development workspace; these files are compressed WebP copies for the game.

Prompt set: photorealistic studio product imagery of the named car model, correct curved body proportions, realistic wheels, glass and lights; full front three-quarter view on the left and direct rear view on the right; transparent background, no people, scenery or UI. Mazda Roadster ND 2015, Toyota GR86 2021, Mazda RX-7 FD Spirit R 2002, BMW M3 E92 2007, Nissan GT-R R35 2017, Toyota GR Supra A90 2020, Honda NSX Type R 1992, Ferrari 458 Italia 2009, Porsche 911 GT3 RS 991 2016. The Lamborghini Veneno coupe uses the user's supplied silver/black/red car photograph as visual reference, preserving the silver paint, carbon aero, red wheel details and large wing in both generated views. The user's original photograph is not included in this repository.

These are illustrative AI renders, not manufacturer photographs or CAD-accurate 3D assets. Vehicle imagery and model names do not imply affiliation with the manufacturers.
